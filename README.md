# Automatic Scanning and Registration of Services

**Descripción.**
Durante el desarrollo de un proyecto es necesario crear multiples servicios, en ocaciones el proyecto crece tanto que es necesario que los servicios 
son demasiados. En caso de tener 100 servicios se deben hacer 100 services.addScopped<IMiServicio, MiServicio>().

**Objetivo.** Con este proyecto se aborda un enfoque para crear los servicios y que el proyecto escanee y los agrege de manera automatica.

1. En el archivo Automatic Scanning and Registration of Services.cs se describen de manera general los pasos seguidos para la implementación de este metodo, asi como en el proyecto se crearon 3 servicios y estos se registran automaticamente.

2. Este enfoque tan solo es una forma, pueden existir otra forma, ni tampoco se asegura que sea la forma más optima.
